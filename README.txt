USAGE (iPhone Chrome / laptop)
1. Open the dashboard. Select a clear 1-minute Binomo Crypto IDX screenshot.
2. If DATA ERROR appears, expand Screenshot quality & chart-area help ->
   Manual chart crop. Trim off toolbar/indicators; Apply crop & re-analyze.
3. Capture a second *different* screenshot after the next minute begins.
4. Read CHART DIRECTION READOUT (directional research only). For timed 1m
   analysis, observe the V3 Pair status, check the same instrument/1m box and
   fresh-screenshot box only when strictly true. WAIT is expected if any
   accuracy, timing, price, volatility, or conflict check fails.
5. The Next Candle decision and its expiry/result review time are separate.
   Log demo outcomes manually or use authorized timestamped 1m OHLC CSV.

LIMITATIONS / SAFETY
- Screenshot candles are approximate pixel-colour estimates, not verified
  Binomo OHLC prices or timestamped candles. Chart time cannot be read
  reliably from arbitrary screenshots; image receipt time is not proof of capture.
- Binance spot data is NOT the same as Binomo Crypto IDX synthetic prices.
- No automated orders, no official Binomo data feed, no guaranteed UP/DOWN,
  winning percentage or profit. This is analysis and demo testing only.
- Data and demo journal stay in your browser. JavaScript local storage may be
  unavailable for local file previews or in some privacy modes.
