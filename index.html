About this MVP

Runs as a static GitHub Pages site without Python, Render, credentials or unofficial Binomo APIs. It does not log in, read hidden site data, access trades, or place orders. It records timestamps and simple pixel statistics from a user-selected visible chart region. To build reliable indicators, we would need actual numeric OHLC candles and validate their extraction against ground truth.
